# ОПИТУВАЛЬНИК

Веб-додаток для створення та проходження онлайн-опитувань.

Користувач може:
- переглядати каталог опитувань;
- фільтрувати опитування за темами;
- проходити опитування та голосувати;
- переглядати результати;
- створювати власні опитування після авторизації.

Дані зберігаються локально у браузері (LocalStorage).

## Технології
- HTML5
- CSS3
- JavaScript
- LocalStorage
